# Security Policy

This policy covers Uninstall Here, the Windhawk mod that opens desktop app uninstallers from the Windows 11 Start menu.

## Supported versions

| Version | Security updates |
| --- | --- |
| Latest release | Supported |

## Reporting a vulnerability

1. If **Report a vulnerability** is available, use it to send a private report. [Repository Security tab](https://github.com/luizbizzio/uninstall-here/security)
2. If private reporting is unavailable, open an issue asking for a private contact method. Keep the public request general and share technical details privately. [Open an issue](https://github.com/luizbizzio/uninstall-here/issues/new)

Include the following details when possible:

- The Uninstall Here version, Windhawk version, and Windows build (`winver`).
- The app or installer involved and steps to reproduce the issue with a test app.
- What happened, what you expected, and the potential security impact.
- Relevant logs or screenshots with personal information removed.

Please coordinate public disclosure with the maintainer so there is time to investigate and prepare a fix.
